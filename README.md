# Capstone_2026_SHREW
Calculations to find rainfall intensity, flow rate and power for prospective buildings of the Self-Harvester Electricity-Water project can be found here. 
University of Washington Civil and Environmental Dept 2026 capstone. The aim of this project was to test the feasiability of implenting a rainwater harvesting 
device across buildings on the UW campus. This notebook was created to work with satellite data at ease and calculate power capabilities of our prospective 
buildings.
